# Restaurant-sql-analysis

## 📌 Overview

This project is a **MySQL-based Restaurant Database and SQL Analysis project**. It demonstrates how SQL can be used to create a relational database and analyze restaurant orders, items, and sales data.

## ✨ Project Highlights

* Designed a relational restaurant database using MySQL.
* Created tables with **primary and foreign key relationships**.
* Inserted and managed sample restaurant data.
* Wrote SQL queries to analyze **orders, items, quantities, and sales**.
* Used **JOIN, GROUP BY, ORDER BY, SUM(), COUNT()**, and filtering techniques.
* Practiced writing SQL queries for practical business-oriented data analysis.

## 📂 Project Files

* **`create_database.sql`** – Creates the database, tables, relationships, and sample data.
* **`analysis_queries.sql`** – Contains SQL queries for analyzing the restaurant data.

## 🛠️ Technologies Used

* MySQL
* SQL
* DBeaver / MySQL Workbench

## ▶️ How to Run

1. Open the project in **DBeaver** or **MySQL Workbench**.
2. Run `create_database.sql` first.
3. Run `analysis_queries.sql`.
4. Review the results generated by the queries.

## 🎯 Objective

To practice SQL and relational database concepts by creating a restaurant database and performing practical data analysis using SQL queries.
